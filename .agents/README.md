# Workspace Customizations

This directory (`.agents`) contains project-specific customizations for Antigravity agents.

- `AGENTS.md`: Master agent guidelines and core behavioral invariants.
- `PROJECT_MEMORY.md`: Complete persistent memory covering architecture, git remotes, deployment, safety gates, and testing runbooks.
- `rules/`: Contains Markdown files that enforce coding standards, safety constraints, git hygiene, and project guidelines.
- `skills/`: Contains progressive-disclosure Markdown files that teach agents complex workflows or procedures.
- `plugins/`: Bundled collections of skills, rules, and MCP configurations.
